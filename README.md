# AI2Word-Thesis
**AI 마크다운 논문 원고 → 연구실 선배 워드 양식 1클릭 변환기**

ChatGPT·Claude 등이 작성한 마크다운(`.md`) 논문 원고를 연구실 선배 논문의 Word(`.docx`) 서식 그대로 입혀 변환해 주는 도구입니다.

> [!IMPORTANT]
> 이 도구는 **문서 서식 및 수식 변환기**입니다. AI 특유의 문체나 통계적 워터마킹까지 제거하지는 않으므로, 변환 전에 패러프레이징 및 문맥 정제를 먼저 진행하세요.

### 핵심 특징
- **진짜 Word 수식(OMML) 변환**: 수식이 이미지가 아니라 **Word 수식 편집기로 바로 편집 가능한 네이티브 수식**으로 들어갑니다.
- **무설치 실행**: Python이나 LaTeX를 따로 설치할 필요가 없으며 **MS Word만 있으면 됩니다.**
- **엔진 자동 준비**: 변환 엔진(`pandoc`)이 없으면 첫 실행 시 자동으로 다운로드합니다.

| 기존 수작업 방식 | AI2Word-Thesis 사용 시 |
| :--- | :--- |
| 수식 30개를 일일이 수식 편집기에 타이핑 (최소 2시간) | 마크다운 원고 붙여넣고 **더블클릭 한 번**으로 변환 |
| 복사·붙여넣기 과정에서 수식 깨짐 및 서식 초기화 | 수식·글꼴·여백·제목 스타일이 적용된 상태로 출력 |
| 마감 직전 밤샘 서식 노가다 | 초안 변환 후 **검수 및 미세 다듬기**에만 집중 |

## 빠른 시작 (딱 3단계)

사용자가 다루는 파일은 **3개**뿐입니다. (나머지 변환 도구는 `engine/` 폴더에서 자동 작동합니다.)

```text
[1]선배양식.docx (서식 기준)  +  [2]원고입력.md (내 마크다운 원고)
                         ↓
             [3]워드로_변환하기.bat (더블클릭)
                         ↓
             [결과]_완성논문.docx (변환 완료!)
```

1. **양식 준비 (`[1]선배양식.docx`)**
   - 연구실 선배 논문 파일에서 본문만 지운 빈 문서를 `[1]선배양식.docx` 이름으로 폴더에 넣습니다. *(없으면 기본 서식으로 변환됩니다.)*
2. **원고 입력 (`[2]원고입력.md`)**
   - AI가 작성한 마크다운 원고를 `[2]원고입력.md`에 붙여넣고 저장합니다 (`UTF-8`).
3. **변환 실행 (`[3]워드로_변환하기.bat`)**
   - 배치 파일을 더블클릭하면 같은 폴더에 **`[결과]_완성논문.docx`**가 생성됩니다.

> [!WARNING]
> `[결과]_완성논문.docx`가 Word에서 열려 있으면 파일을 덮어쓸 수 없습니다. **변환 전 반드시 Word 창을 닫아 주세요.**

> [!NOTE]
> **첫 실행 안내**: `engine/pandoc.exe`가 없으면 최초 실행 시 자동으로 다운로드됩니다 (약 10~20초 소요, 인터넷 연결 필요). 두 번째 실행부터는 즉시 변환됩니다.

## 선배 양식 입히는 법 (핵심 기능)

`[1]선배양식.docx`에 저장된 **글꼴·글자 크기·줄간격·여백·제목 스타일**을 새 문서에 그대로 복사해 입힙니다.

1. 연구실 선배의 논문 `.docx` 파일을 복사합니다.
2. Word에서 파일을 열고 `Ctrl + A` → `Delete`를 눌러 **본문 내용만 모두 지웁니다.** *(문서에 정의된 스타일과 여백은 그대로 남습니다.)*
3. 파일 이름을 **`[1]선배양식.docx`**로 저장하여 이 폴더의 기존 파일에 덮어씁니다.
4. `[3]워드로_변환하기.bat`을 실행하면 선배 논문의 서식이 적용된 결과물이 나옵니다.

## 지원하는 수식 문법

마크다운 내 LaTeX 수식을 Word 네이티브 수식(OMML)으로 변환합니다. 결과 문서에서 수식을 클릭하면 Word 수식 편집기로 즉시 수정할 수 있습니다.

| 마크다운 작성법 | 변환 결과 |
| :--- | :--- |
| `$...$` 또는 `\(...\)` | 문장 안 인라인 수식 |
| `$$...$$` 또는 `\[...\]` | 별도 줄 블록 수식 |
| `\begin{aligned} ... \end{aligned}` | 여러 줄 등호 정렬 수식 |
| `\begin{cases} ... \end{cases}` | 조건별 경우 나누기 수식 |
| `\frac{a}{b}`, `\sum_{i=1}^{n}`, `\sqrt{x}` | 분수, 시그마, 제곱근 등 일반 LaTeX 기호 |

## 긴 논문 작업 팁 (40~50페이지 이상)

분량이 많은 논문을 한 번에 통째로 변환하면 복잡한 표 너비나 긴 수식에서 간혹 줄바꿈이 어긋날 수 있습니다. **챕터별로 나누어 변환한 뒤 조립하는 방식**이 가장 빠르고 깔끔합니다.

1. **챕터별 분할 변환**: `1장_서론.md`, `2장_이론배경.md`처럼 장 단위로 나누어 변환합니다.
2. **결과물 조립**: 잘 변환된 본문과 수식을 최종 논문 파일에 복사해 이어 붙입니다.
3. **마무리 다듬기**: 표 너비나 줄바꿈이 어색한 일부 구간(5~10%)만 Word에서 직접 다듬습니다.

## 폴더 구조

```text
AI2Word-Thesis/
├─ [1]선배양식.docx        # 서식 기준 파일 (내 연구실 양식으로 교체)
├─ [2]원고입력.md          # 변환할 마크다운 원고 입력 파일
├─ [3]워드로_변환하기.bat   # 변환 실행 파일 (더블클릭)
├─ [결과]_완성논문.docx    # 변환 완료된 Word 문서 (자동 생성)
├─ README.md               # 사용 설명서
└─ engine/                 # 내부 변환 엔진 (수정 불필요)
   ├─ pandoc.exe           # 최초 실행 시 자동 다운로드
   ├─ fix_md.py            # 마크다운 전처리 및 수식 보호 스크립트
   ├─ style.lua            # 표 서식 보정 Lua 필터
   └─ license/             # pandoc GPL 라이선스 전문
```

## 문제 해결 (FAQ)

| 증상 | 원인 및 해결 방법 |
| :--- | :--- |
| **결과 파일이 생성되지 않음** | Word에서 `[결과]_완성논문.docx`가 열려 있는지 확인하고 닫은 뒤 다시 실행하세요. |
| **수식이 `$...$` 글자 그대로 보임** | `$` 기호의 여닫는 짝이 맞는지 확인하고, 블록 수식(`$$`) 앞뒤에 빈 줄을 넣어 주세요. |
| **여러 줄 수식이 한 줄로 깨짐** | 수식 줄바꿈을 `\` 하나가 아닌 **`\\` (두 개)**로 작성했는지 확인하세요. |
| **자동 다운로드 실패** | 인터넷 연결을 확인한 후 `[3]워드로_변환하기.bat`을 다시 실행하세요. |
| **선배 양식이 적용되지 않음** | 파일 이름이 정확히 `[1]선배양식.docx`인지, 문서 안에 Word 스타일이 포함되어 있는지 확인하세요. |
| **한글이 깨져서 나옴** | `[2]원고입력.md` 파일을 **UTF-8** 인코딩으로 저장했는지 확인하세요. |
| **표가 깨지거나 본문과 붙음** | 마크다운 표 바로 위아래에 **빈 줄**을 한 줄씩 추가하세요. |

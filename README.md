# AI2Word-Thesis — AI 마크다운 논문 → 선배 워드 양식 1클릭 변환기

ChatGPT·Claude가 써준 마크다운 원고를, 연구실 선배 논문의 워드 양식 그대로 입혀서 .docx로 뽑아주는 도구입니다. (AI의 통계적 워터마킹까지 제거해 주지는 않습니다. 변환전 반드시 패러프레이징 변환기 등을 적용해 문맥을 정제하십시오.)

- 수식은 그림이 아니라 **Word 수식 편집기로 열리는 진짜 수식(OMML)** 으로 변환됩니다
- 설치할 것이 없습니다. Python도, LaTeX도 필요 없고 **Word만 있으면 됩니다**
- 엔진(pandoc)은 첫 실행 때 자동으로 받아오니, 그것도 신경 쓸 필요 없습니다

| 일반적인 방법 | 이 도구를 쓰면 |
|---|---|
| 워드에 수식 30개를 하나하나 타이핑 (최소 2시간) | 원고 붙여넣고 더블클릭 한 번이면 완성 |
| 수식 깨짐·서식 날림으로 감점 | 수식·폰트 서식이 90% 완성된 상태로 문서가 나옴 |
| 마감 전날 밤샘 서식 작업 | 사람은 검수하고 다듬기만 하면 됨 |

---

## 사용법 — 딱 3단계

사용자가 만질 파일은 3개뿐입니다. 나머지는 `engine/` 폴더 안에 숨어 있어요.

**1단계. 양식 준비**
선배 논문 파일에서 본문만 지운 빈 문서를 `[1]선배양식.docx` 라는 이름으로 이 폴더에 넣어두세요. 자세한 방법은 아래 "선배 양식 바꾸는 법"에 있습니다. (없으면 pandoc 기본 서식으로 변환됩니다.)

**2단계. 원고 붙여넣기**
AI가 작성한 마크다운 원고를 `[2]원고입력.md` 에 붙여넣고 저장하세요.

**3단계. 더블클릭**
`[3]워드로_변환하기.bat` 을 더블클릭하면 같은 폴더에 `[결과]_완성논문.docx` 가 생깁니다. 끝입니다.

> 결과 파일이 Word에서 열려 있으면 덮어쓰지 못합니다. 변환 전에 Word 창을 닫아 주세요.

### 처음 실행할 때만: pandoc 자동 다운로드

- `engine\pandoc.exe` 가 없으면 첫 실행 때 자동으로 다운로드됩니다 (약 10~20초, 인터넷 필요)
- 두 번째 실행부터는 바로 변환됩니다

## 선배 양식 바꾸는 법 (이 도구의 핵심)

`[1]선배양식.docx` 의 스타일·여백·글꼴을 새 문서에 그대로 입히는 게 이 도구의 핵심 기능입니다.

1. 연구실 선배의 논문 Word 파일을 복사합니다
2. 열고 `Ctrl + A` → `Delete` 로 본문만 전부 지웁니다 (서식과 스타일만 남습니다)
3. `[1]선배양식.docx` 라는 이름으로 저장해서 이 폴더의 기존 파일에 덮어씁니다
4. 변환을 다시 실행하면 선배 논문의 글꼴·글자 크기·줄간격·제목 스타일·여백이 적용됩니다

---

## 수식은 어떻게 변환되나요?

엔진인 pandoc이 마크다운 속 LaTeX 수식을 Word 네이티브 수식(OMML)으로 바꿉니다. 변환된 수식은 Word에서 클릭하면 수식 편집기가 열려 바로 고칠 수 있습니다.

| 마크다운에 쓰는 법 | 변환 결과 |
|---|---|
| `$...$` 또는 `\( ... \)` | 문장 안 인라인 수식 |
| `$$ ... $$` 또는 `\[ ... \]` | 별도 줄 블록 수식 |
| `\begin{aligned} ... \end{aligned}` | 여러 줄 정렬 수식 |
| `\begin{cases} ... \end{cases}` | 경우 나누기 수식 |
| `\frac{a}{b}`, `\sum_{i=1}^{n}`, `\sqrt{x}` | 분수·시그마·제곱근 등 |

## 긴 논문은 이렇게 작업하세요 (실전 노하우)

40~50페이지가 넘는 논문은 한 번에 변환하면 표 너비나 복잡한 수식에서 미세하게 어긋나는 구간이 생길 수 있습니다. 실제 40페이지 졸업논문을 하루 만에 완성한 방식은 "챕터별로 변환해서, 잘 나온 부분만 골라 조립하기"입니다.

1. **챕터별로 변환** — `1장_서론.md`, `2장_수식_이론.md` 처럼 나눠서 변환기를 돌립니다
2. **골라서 조립** — 변환 결과에서 수식과 본문이 깔끔하게 나온 부분만 복사해 최종 논문 파일에 이어 붙입니다
3. **마무리 수습** — 줄바꿈이 어색하거나 표가 좁아진 5~10% 구간만 워드에서 직접 다듬습니다

수식을 손으로 타이핑하는 시간(개당 3~5분)이 통째로 사라지기 때문에, 전체 작업이 비교할 수 없이 빨라집니다.

## 폴더 구조

```
AI_논문_변환기_배포/
├─ [1]선배양식.docx        ← 서식 기준 (교체 가능)
├─ [2]원고입력.md          ← 내 원고 (예시 포함)
├─ [3]워드로_변환하기.bat     ← 더블클릭 실행
├─ [결과]_완성논문.docx      ← 실행하면 자동 생성
├─ README.md               ← 이 문서
├─ .gitignore
└─ engine/                 ← 변환 엔진 (건드리지 않아도 됨)
   ├─ pandoc.exe           ← 최초 실행 시 자동 다운로드
   ├─ fix_md.py            ← 원고 전처리 (비파괴, 수식 보호)
   ├─ style.lua            ← 표 서식 Lua 필터
   └─ license/             ← pandoc GPL 라이선스
```

## 문제가 생기면

| 증상 | 확인할 것 |
|---|---|
| 결과 파일이 안 생김 | Word에서 결과 파일을 열어 둔 상태인지 확인 |
| 수식이 `$...$` 글자 그대로 보임 | `$` 짝이 맞는지, 블록 수식 앞뒤에 빈 줄이 있는지 확인 |
| 여러 줄 수식이 깨짐 | 줄바꿈을 `\` 가 아니라 `\\` 로 썼는지 확인 |
| 자동 다운로드 실패 | 인터넷 연결 확인 후 다시 실행 |
| 선배 양식이 적용 안 됨 | `[1]선배양식.docx` 가 있는지, 스타일이 있는 문서인지 확인 |
| 한글이 깨짐 | 원고 파일을 UTF-8로 저장 |
| 표가 깨짐 | 표 바로 앞뒤에 빈 줄 넣기 |

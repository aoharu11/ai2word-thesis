# AI2Word-Thesis — AI 마크다운 논문 → 선배 워드 양식 1클릭 변환기

> **ChatGPT/Claude가 써준 마크다운 논문, 연구실 선배 워드 양식 그대로 1초 만에 입혀드립니다.**

| ❌ 전에 | ⭕ 이 도구 사용 후 |
|---|---|
| 워드 켜놓고 마우스로 분수·시그마 하나하나 타이핑 (수식 30개 = 최소 2시간) | AI 원고 + 선배 양식 → 더블클릭 한 번으로 규격 문서 완성 |
| 수식 깨짐·서식 날림으로 감점 | 수식은 Word 네이티브 수식(OMML)로 변환, 클릭해서 수정 가능 |
| 졸업논문 마감 전날 밤샘 서식 노가다 | 수식과 폰트 서식이 90% 완성된 상태로 워드에 입수 |

수식은 **그림이 아니라 Word 수식 편집기로 열리는 진짜 수식**입니다.
인터넷 연결, Python 설치, LaTeX 설치가 필요 없습니다. **Word만 있으면 됩니다.**

---

## 🚀 사용법 (딱 3스텝)

사용자가 볼 파일은 딱 3개입니다. 나머지 엔진은 `engine/` 폴더에 숨어 있습니다.

### 스텝 1 — `[1]선배양식.docx` 준비하기

연구실 선배의 논문 Word 파일을 복사해 본문만 지우고, `[1]선배양식.docx` 라는 이름으로 저장하세요. (서식과 스타일만 남은 빈 문서가 됩니다.)

> 없으면 pandoc 기본 서식으로 변환됩니다.

### 스텝 2 — `[2]원고입력.md` 에 원고 붙여넣기

ChatGPT/Claude가 작성한 마크다운 원고를 `[2]원고입력.md` 에 붙여넣고 저장하세요.

### 스텝 3 — `[3]워드로_변환하기.bat` 더블클릭

더블클릭 한 번이면 끝입니다. 같은 폴더에 **`[결과]_완성논문.docx`** 가 생성됩니다.

> `[결과]_완성논문.docx` 가 Word에서 열려 있으면 덮어쓰지 못합니다. 변환 전에 Word 창을 닫아 주세요.

---

## ⚡ Pandoc 자동 설치 (최초 1회만)

별도로 Pandoc을 다운로드할 **필요가 없습니다.**

- `engine\pandoc.exe` 가 없으면 첫 실행 때 **자동으로 다운로드**됩니다 (약 10~20초).
- 두 번째부터는 즉시 변환됩니다.
- 인터넷 연결이 필요합니다.

---

## 📐 수식이 어떻게 워드 수식으로 변환되나요?

이 도구는 pandoc을 엔진으로 사용합니다.

```
마크다운 + LaTeX ($$ ... $$, \begin{aligned}, \begin{cases} 등)
       │ pandoc 변환
       ▼
Word 문서(.docx) 안의 OMML (Office Math Markup)
```

- `$...$` 또는 `\( ... \)` → 문단 안 인라인 수식
- `$$ ... $$` 또는 `\[ ... \]` → 별도 줄 블록 수식
- `\begin{aligned} ... \\ ... \end{aligned}` → 여러 줄 정렬 수식
- `\begin{cases} ... \end{cases}` → 경우 나누기 수식
- `\frac{a}{b}`, `\sum_{i=1}^{n}`, `\sqrt{x}` 등 → 분수·시그마·제곱근 등

변환된 수식을 Word에서 **클릭하면 수식 편집기 창이 열려** 바로 수정할 수 있습니다.

## 💡 실전 추천: 40페이지 하루 컷을 만든 '조립식(Hybrid) 워크플로우'

> **"Word 수식 타이핑과 서식 노가다를 90% 덜어내는 것이 이 도구의 진짜 목적입니다."**

아무리 뛰어난 변환 툴도 40~50페이지가 넘어가는 대형 논문에서는 표(Table) 너비나 복잡한 다단 수식에서 미세한 서식 어긋남이 발생할 수 있습니다.

실제 40페이지 졸업논문을 단 하루 만에 완성했을 때 사용한 **가장 빠르고 안전한 실전 조립법**을 권장합니다.

```
[ChatGPT / Claude]
       │ (챕터별 마크다운 초고 작성)
       ▼
 [원고입력.md] ──(변환기 실행)──> [output.docx] (변환 결과물)
                                         │
                                         ▼ [눈으로 쓱 검수]
                              ┌──────────────────────┐
                              │  완벽하게 나온 수식·본문만  │
                              │     새 워드 파일에 복붙!     │
                              └──────────────────────┘
                                         │
                                         ▼
                               [최종 제출용 논문.docx]
```

### 권장 작업 순서 (Best Practice)

1. **챕터별 변환:**  
   40페이지를 한 번에 굽기보다, `1장_서론.md`, `2장_수식_이론.md`처럼 챕터별로 변환기를 돌립니다.

2. **선별 복사 & 조립 (인간 필터링):**  
   변환된 워드(`[결과]_완성논문.docx`)를 열어보고, **네이티브 수식과 본문이 깔끔하게 나온 부분을 복사**하여 최종 제출용 새 워드 파일에 차례대로 이어붙입니다.

3. **미세 수습:**  
   혹시 줄바꿈이 어색하거나 표 너비가 좁아진 5~10%의 구간만 최종 워드에서 마우스로 살짝 다듬어 줍니다.

> **이 방식이 왜 압도적으로 빠른가요?**  
> * 워드에서 수식 하나 직접 타이핑하는 데 3~5분이 걸립니다. (수식 30개 = 최소 2시간)  
> * 이 파이프라인을 쓰면 **수식과 폰트 서식이 이미 90% 완성된 상태로 워드에 들어가기 때문에**, 사람은 '검수하고 붙여넣기'만 하면 됩니다.  
> * 워드 특유의 파일 깨짐이나 렉(Lag) 현상도 완벽히 예방할 수 있습니다.

## 🎓 선배 논문 양식 복제하는 법 (핵심)

이 도구의 핵심은 **`[1]선배양식.docx`** 입니다. 이 파일의 스타일·여백·글꼴을 그대로 새 문서에 입힙니다.

1. 연구실 선배의 논문 Word 파일을 복사합니다.
2. 문서를 열고 `Ctrl + A` → `Delete` 로 **본문 내용만 전부 지웁니다.** (서식과 스타일만 남은 빈 문서가 됩니다.)
3. 그 빈 파일을 `[1]선배양식.docx` 라는 이름으로 저장합니다.
4. 이 폴더의 기존 파일에 덮어씁니다.
5. `[3]워드로_변환하기.bat` 을 다시 실행합니다.

그러면 선배 논문의 **글꼴, 글자 크기, 줄간격, 제목 스타일, 여백**이 새 문서에 적용됩니다.

`[1]선배양식.docx` 를 지우면 pandoc 기본 서식으로 변환됩니다.

## 📁 폴더 구조

```
AI_논문_변환기_배포/
├─ [1]선배양식.docx     ← 서식 기준 (교체 가능)
├─ [2]원고입력.md       ← 내가 쓰는 원고 (예시 포함)
├─ [3]워드로_변환하기.bat  ← 더블클릭 실행
├─ [결과]_완성논문.docx   ← 실행하면 자동 생성
├─ README.md            ← 이 문서
├─ .gitignore           ← Git 무시 설정
└─ engine/              ← 변환 엔진 (건드리지 않아도 됨)
   ├─ pandoc.exe        ← 변환 엔진 (최초 실행 시 자동 다운로드)
   ├─ fix_md.py         ← 원고 전처리 (비파괴, 수식 보호)
   ├─ style.lua         ← 표 서식 Lua 필터
   └─ license/          ← pandoc GPL 라이선스
```

## ❓ 자주 나는 문제

| 증상 | 확인할 것 |
|---|---|
| `[결과]_완성논문.docx` 가 안 생김 | Word에서 파일을 열어 둔 상태인지 확인 |
| 수식이 `$...$` 글자로 보임 | `$`의 짝이 맞는지, 블록 수식 앞뒤에 빈 줄이 있는지 확인 |
| 여러 줄 수식이 깨짐 | 줄바꿈을 `\`가 아니라 `\\`로 썼는지 확인 |
| 자동 다운로드가 실패함 | 인터넷 연결을 확인하고 다시 실행 |
| 선배 양식이 적용 안 됨 | `[1]선배양식.docx`가 있는지, 스타일 기반 문서인지 확인 |
| 한글이 깨짐 | 원고 파일을 UTF-8로 저장 |
| 표가 깨짐 | 표 바로 앞뒤에 빈 줄 넣기 |

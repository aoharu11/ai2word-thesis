## 🚀 1분 퀵스타트: 사용법 (Quick Start)

폴더를 열면 보이는 파일은 **딱 3개**입니다. (복잡한 변환 엔진은 `engine/`에 숨겨져 있습니다.)

| 순서 | 파일 | 할 일 |
| :---: | :---|---|
| **Step 1** | **`[1]선배양식.docx`** | 연구실 선배 논문 파일의 본문만 지우고 이 이름으로 저장 |
| **Step 2** | **`[2]원고입력.md`** | AI(ChatGPT/Claude)가 작성해 준 마크다운 텍스트를 붙여넣기 |
| **Step 3** | **`[3]워드로_변환하기.bat`** | **더블클릭 실행** → `[결과]_완성논문.docx` 자동 생성 완료! |

> ⚠️ **주의사항:** Word에서 `[결과]_완성논문.docx`를 열어둔 상태로 변환기를 돌리면 파일 쓰기 권한 에러가 납니다. 변환 전에는 반드시 Word 창을 닫아주세요.

## 🎓 핵심 치트키: '선배 논문 양식' 10초 만에 복제하기

이 도구의 진가는 **선배 논문의 여백, 글꼴(바탕/명조), 자간, 줄간격, 제목 서식**을 그대로 강제 상속받는 데 있습니다.

1. 통과된 연구실 선배의 논문 Word 파일(`.docx`)을 하나 구합니다.
2. 문서를 열고 `Ctrl + A` → `Delete`를 눌러 **본문 내용(글자, 그림, 표)만 싹 지웁니다.**  
   *(눈에 보이는 글은 없지만, 문서 내부에는 선배 논문의 폰트와 여백 스타일이 그대로 남아있습니다.)*
3. 그 빈 문서를 **`[1]선배양식.docx`**라는 이름으로 이 폴더에 덮어씁니다.
4. 이제 변환기를 돌리면, AI가 쓴 글이 **우리 연구실 공식 규격 워드 문서**로 둔갑합니다.

*(※ `[1]선배양식.docx` 파일이 없으면 Pandoc의 기본 깔끔한 서식으로 자동 생성됩니다.)*

## 💡 실전 추천: 40페이지 하루 컷을 만든 '조립식 워크플로우'

> **"Word 수식 타이핑과 서식 노가다를 90% 삭제하는 것이 이 도구의 진짜 목적입니다."**

대형 학위논문(30~50페이지 이상)을 작성할 때는 50페이지를 한 번에 굽기보다, **가장 빠르고 안전한 '하이브리드 조립식 방식'**을 강력 추천합니다.

```text
[ChatGPT / Claude]
       │ (1장, 2장 등 챕터별 마크다운 초고 생성)
       ▼
 [2]원고입력.md ──([3]워드로_변환하기.bat)──> [결과]_완성논문.docx (변환 결과)
                                                       │
                                                       ▼ [눈으로 쓱 검수]
                                            ┌──────────────────────┐
                                            │  완벽하게 나온 수식·본문만 │
                                            │     새 워드 파일에 복붙!   │
                                            └──────────────────────┘
                                                       │
                                                       ▼
                                             [최종_제출용_졸업논문.docx]
```

### 권장 작업 순서 (Best Practice)
1. **챕터별 변환:** `1장_서론.md`, `2장_수식_이론.md`처럼 챕터별로 마크다운을 넣고 변환합니다.
2. **선별 조립 (인간 필터링):** 생성된 워드 문서를 열어보고, **네이티브 수식과 본문이 완벽하게 나온 부분을 최종 제출용 워드에 차례로 복붙**합니다.
3. **미세 수습:** 혹시 줄바꿈이 어색하거나 표 너비가 좁아진 5~10% 구간만 최종 워드에서 마우스로 살짝 다듬어 줍니다.

> **왜 이 방식이 압도적으로 빠른가요?**  
> * 워드에서 수식 하나 직접 마우스로 치는 데 3~5분이 걸립니다. (수식 30개 = 최소 2시간)  
> * 이 파이프라인을 쓰면 **수식과 폰트 서식이 이미 90% 완성된 상태로 워드에 입수**되므로, 사람은 '검수하고 이어붙이기'만 하면 됩니다.  
> * 워드 특유의 40페이지 넘어가면 생기는 렉(Lag)과 서식 꼬임도 완벽히 예방됩니다.

## 📐 기술 원리: 어떻게 워드 네이티브 수식이 되나요?

이 도구는 내장된 `pandoc 3.8.3` 엔진과 전처리 필터를 거쳐 동작합니다.

```text
Markdown + LaTeX ($$, \aligned, \cases 등)
       │
       ▼ [engine/fix_md.py] (수식 깨짐 방지 플레이스홀더 보호)
       │
       ▼ [engine/pandoc.exe]
Word 문서(.docx) 내부의 OMML (Office Math Markup Language) 객체로 번역
```

* `$x$` 또는 `\(x\)` $\to$ 문단 내 인라인 수식
* `$$\frac{a}{b}$$` 또는 `\[ ... \]` $\to$ 중앙 정렬 블록 수식
* `\begin{aligned} ... \end{aligned}` $\to$ 등호(`=`) 기준 정렬 수식
* `\begin{cases} ... \end{cases}` $\to$ 조건부 분기 수식

변환된 수식은 이미지가 아니므로, **Word에서 클릭하면 상단 리본 메뉴에 [수식] 탭이 활성화되며 직접 수정**할 수 있습니다.

## 🛠 GitHub 클론 및 배포 안내

### pandoc.exe 파일 크기 주의 (228MB)
GitHub은 단일 파일 100MB 초과 시 Push를 차단합니다. 본 저장소의 `.gitignore`에는 `engine/pandoc.exe`가 이미 등록되어 있어 안심하고 Git에 Push하셔도 됩니다.

* **저장소를 Clone 받은 경우:**  
  [Pandoc 공식 릴리스](https://github.com/jgm/pandoc/releases)에서 Windows용 zip을 받아 `pandoc.exe` 파일만 `engine/` 폴더 안에 넣어주시면 즉시 작동합니다.
* **지인/동기에게 배포할 경우:**  
  `pandoc.exe`가 포함된 상태로 폴더 전체를 `.zip`으로 압축하여 전달하면, 받는 사람은 아무런 설치 없이 압축 해제 후 바로 사용할 수 있습니다.

## ❓ 자주 묻는 질문 (FAQ & Troubleshooting)

**Q. `[결과]_완성논문.docx` 파일이 생기지 않아요.**  
A. 이미 워드에서 이전 결과물 파일을 열어두지 않았는지 확인하세요. 열려 있다면 Word 창을 닫고 다시 실행하세요.

**Q. 수식이 변환되지 않고 `$ ... $` 텍스트 그대로 나와요.**  
A. 수식 앞뒤의 `$` 기호 짝이 맞는지 확인하시고, 블록 수식(`$$ ... $$`) 앞뒤에는 반드시 빈 줄을 하나씩 띄워주세요.

**Q. 여러 줄 수식 정렬이 깨져요.**  
A. 줄바꿈 기호가 `\` 1개가 아니라 `\\` 2개로 들어가 있는지 확인하세요.

**Q. 한글이 네모(□)로 깨져 나와요.**  
A. `[2]원고입력.md` 파일을 저장할 때 인코딩이 **`UTF-8`**로 되어 있는지 확인하세요. (메모장에서 [다른 이름으로 저장] 시 인코딩을 UTF-8로 지정)
